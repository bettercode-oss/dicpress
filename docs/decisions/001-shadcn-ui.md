# ADR 001: shadcn/ui 채택

## 상태

채택 (2026-08-15)

## 배경

관리자 화면에 인라인 도움말 툴팁이 필요해졌다. 자체 구현, Headless UI, shadcn/ui(Radix 기반) 세 가지를 검토했다.

## 결정

shadcn/ui를 채택한다.

## 근거

- **접근성**: Radix UI 기반으로 키보드 탐색·포커스 트랩·ARIA 속성이 기본 내장된다. 자체 구현 시 이를 모두 직접 처리해야 한다.
- **충돌 회피**: Floating UI를 사용하는 Tooltip이 뷰포트 경계를 자동으로 감지해 화면 밖으로 잘리지 않는다.
- **소유권**: 컴포넌트 소스를 `components/ui/`에 직접 복사하는 방식이라 외부 패키지 업그레이드 충돌 없이 자유롭게 수정 가능하다.
- **Tailwind v4 호환**: shadcn v4가 Tailwind v4를 공식 지원한다.

## 트레이드오프

번들에 Radix 패키지(`@radix-ui/react-tooltip` 등)가 추가된다. 그러나 사용하는 컴포넌트만 설치하므로 전체 UI 라이브러리 대비 크기가 작다.
